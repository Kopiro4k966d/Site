# Crysea: запуск сайта и продажи

## 1. База данных (один раз и после каждого обновления схемы)
1. Скопируйте `.env.example` в `.env`, впишите `DATABASE_URL` (Neon / Supabase / любой Postgres 13+).
2. `npm install` → `npm run db:init`. Команда безопасна для повторного запуска: добавит новые таблицы (коды авторов, отзывы) и колонки в уже существующую базу.

## 2. Переменные окружения на хостинге (Netlify или Vercel)
| Переменная | Для чего |
|---|---|
| `DATABASE_URL` | подключение к Postgres |
| `SITE_URL` | адрес сайта без слеша в конце |
| `LICENSE_PRIVATE_KEY` | `npm run keys`, публичный ключ положить в конфиг приложения |
| `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET` | боевая оплата. Webhook в кабинете ЮKassa: `https://ВАШ-САЙТ/api/webhook/yookassa`, событие `payment.succeeded` |
| `DEMO_PAY=1` | ТОЛЬКО для проверки: тариф включается без оплаты. На боевом сайте не задавать |

## 3. Что заполнить перед продажами
- `public/config.js`: ссылка-приглашение Discord и прямая ссылка на установщик (`.exe`).
- `public/legal.html`: ваши данные вместо `[...]`, условия возврата. Покажите текст юристу, ЮKassa проверяет оферту.
- `public/script.js`, массив `SEED`: сейчас там тексты-заглушки. Замените их настоящими отзывами из Discord или удалите.
- Домен: когда он будет, добавьте в `index.html` теги `og:url` и `og:image` (картинка 1200×630, абсолютная ссылка) и файл `sitemap.xml`.

## 4. Коды авторов (скидки)
Создать код (в SQL-консоли базы):
```sql
insert into promo_codes(code, percent, creator, max_uses) values ('QCOLD', 15, 'Q-Cold', null);
```
`max_uses` = лимит оплаченных покупок, `null` = без лимита. Выключить: `update promo_codes set active=false where code='QCOLD';`
Продажи по коду автора: `select promo, count(*), sum(amount_rub) from payments where status='paid' and promo is not null group by promo;`

## 5. Отзывы
Отзывы с сайта попадают в таблицу `reviews` со статусом `approved=false` и не показываются, пока вы не одобрите:
```sql
select id, name, text from reviews where not approved;
update reviews set approved=true where id='...';
```

## 6. Не забудьте
- Файл `.env` с реальными паролями базы нельзя выкладывать и отправлять. В этом архиве его нет. Если вы уже отправляли `.env` кому-то (в том числе в чат), смените пароль базы и ключ лицензий.
- «Забыли пароль?» сейчас ведёт в Discord. Для автоматического сброса нужен почтовый сервис (Resend, Postmark).
- Вход через Discord и Google пока помечен «скоро»: для него нужны ключи OAuth от этих сервисов.
