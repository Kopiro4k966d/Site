# Crysea (Electron), версия 2.0.0

Приложение для Windows: меняет насыщенность, контраст и яркость всего экрана (в том числе в играх),
умеет профили для отдельных игр, быстрые оптимизации, прицел поверх игры, три темы оформления (тёмная, светлая и мягкая: глубокий сине-бирюзовый фон #002D40 и акцент #1AA6B7) и работу из трея. Интерфейс выполнен в стиле сайта Crysea.

## Запуск
1. Установите Node.js 18+.
2. В папке проекта: `npm install`, затем `npm start`.

## Сборка установщика
`npm run dist`. Готовый установщик появится в папке `dist/`.

## Как это работает
- Цвет меняется через системный Windows Magnification API (скрипт `native/mag.ps1`). Драйверы и внедрение в игры не нужны.
- Эффект действует на игры в оконном и безрамочном режиме. В «настоящем» полноэкранном режиме часть игр его обходит.
- Горячая клавиша **Ctrl+Alt+S** включает и выключает эффект.
- Вкладка **«Прицел»** (как в Crosshair X): крест, точка, круг, T-образный, контур, цвет, прозрачность, сдвиг, готовые пресеты и код для обмена. Прицел рисуется отдельным прозрачным окном поверх игры по центру главного монитора, мышь через него проходит. Горячая клавиша **Ctrl+Alt+C**.
- Для Rust есть быстрый профиль `RustClient.exe` (вкладка «Профили»): при запуске игры применяется насыщенность и высокий приоритет процесса.
- Профили игр определяются по имени процесса (`game.exe`) и применяются автоматически.
- Некоторым оптимизациям (схема питания) могут понадобиться права администратора.
- Настройки хранятся в `settings.json` в папке данных приложения.

## Шрифты
Manrope, Inter и Oswald подтягиваются из Google Fonts. Без интернета подставятся Segoe UI и Bahnschrift. Чтобы шрифты были всегда, положите файлы в `renderer/fonts` и подключите через `@font-face`.

## Окно и палитра
- Окно фиксированного размера 1100×760, все вкладки помещаются без прокрутки. Вкладки стоят по центру шапки.
- Выбор цвета (прицел, контур) сделан своей палитрой: квадрат насыщенности, ползунок оттенка, RGB, HEX и пипетка. Она берёт цвета текущей темы, быстрые цвета тоже зависят от темы.
- Если в сохранённых настройках осталась старая тема (OLED или ретро), при запуске она заменится на тёмную.
- Вкладка «Профиль» открывается по кругу с аватаром справа в шапке: имя, цвет аватара и сводка текущих настроек. Вкладку «Монитор» убрал.

## Тарифы и лицензия
Какие функции в каком тарифе, задаётся одной таблицей `FEATURES` в начале блока «Лицензия и тарифы» в `main.js`.

| Функция | Тариф |
|---|---|
| Цвет экрана (насыщенность, контраст, яркость) | Free |
| Профили игр, свой прицел, быстрые модули оптимизации, вкладка Rust (запуск, консоль, свои модули, вайп) | Pro |
| Авто-режим Rust, рейд-калькулятор | Plus |

Тариф приходит с сервера в виде подписанной лицензии (Ed25519). Публичный ключ лежит в `config.json` (`licenseKey`), поэтому поменять тариф правкой файлов на ПК нельзя. Без интернета лицензия работает 7 дней. Ограничения проверяются в главном процессе, а не только в интерфейсе.

## config.json
- `apiUrl`: адрес API, например `https://ваш-сайт.netlify.app/api`
- `siteUrl`: адрес сайта (кнопки «Купить» и «Улучшить» открывают его раздел тарифов)
- `discordUrl`: ссылка-приглашение на ваш Discord (иконка в шапке)
- `licenseKey`: публичный ключ из `npm run keys` на стороне сайта

Перед сборкой установщика впишите боевые значения. Без `licenseKey` приложение работает в режиме разработки и верит ответу сервера без проверки подписи, поэтому для продажи ключ обязателен.

## Rust
Вкладка Rust (Pro): генератор параметров запуска Steam со своими флагами, команды консоли F1 (свои, с включением и копированием), свои модули оптимизации (набор действий плюс закрытие или понижение приоритета выбранных программ), таймер вайпа с уведомлением, рейд-калькулятор (Plus), кнопка запуска Rust через Steam. Crysea не вмешивается в игру: никаких внедрений, автоматизации отдачи и подсветки врагов.

## Аккаунт и синхронизация
- Вкладка «Профиль»: вход и регистрация. Аккаунт общий с сайтом.
- Синхронизируются имя, цвет аватара, тема, настройки экрана, профили игр, прицел, модули и настройки Rust (кроме пути к игре). Тариф приходит с сайта.
- Вход через Discord и Google: кнопки на вкладке «Профиль» открывают браузер, после подтверждения приложение входит само. Работает, когда на сайте заданы ключи (`ВХОД_DISCORD_GOOGLE.md` в папке сайта).
- Токен входа хранится зашифрованным (Windows DPAPI через safeStorage), пароль на ПК не сохраняется.

## Прозрачность окна и горячие клавиши
Настройки → «Прозрачность окна» (40–100%) и «Горячие клавиши»: три действия, любые свои сочетания.
