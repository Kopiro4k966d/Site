# Crysea — сайт, кабинет и оплата

## Структура
- `public/` — статика: главная, кабинет, оферта и политика (`legal.html`), админка партнёров.
- `netlify/functions/api.mjs` — весь бэкенд (сессии, ЮKassa, отзывы, партнёрка). Тот же код работает на Vercel через `api/index.js`.
- `db/schema.sql` — схема PostgreSQL. `npm run db:init` создаёт таблицы.
- `middleware.js` — защита `/admin` (по желанию, через `ADMIN_IP_ALLOWLIST`).
- `scripts/` — проверка перед запуском (`npm run check`), генерация ключей, тесты партнёрки.

## Переменные окружения
См. `.env.example`. Боевой сайт: `DEMO_PAY` не задавать.

## Перед продажей (чеклист)
1. **Оферта и политика**: заполнить все поля в `[квадратных скобках]` в `public/legal.html`, показать юристу. Убрать жёлтый блок «Шаблон» в начале страницы.
2. **Хранение данных в РФ**: база и API должны работать на российском хостинге (например Yandex Cloud, Selectel, VK Cloud, Timeweb). До переноса политика конфиденциальности не должна публиковаться: в ней уже написано, что данные хранятся в РФ.
3. **Роскомнадзор**: подать уведомление об обработке персональных данных на pd.rkn.gov.ru до начала продаж.
4. **Статус продавца**: самозанятый или ИП. ЮKassa без этого не подключит приём оплаты.
5. **Шрифты**: сейчас подключаются с fonts.googleapis.com. Лучше разместить файлы шрифтов на своём сайте.
6. **Вход через Discord**: Discord ограничен в РФ. Кнопка включается только если заданы `DISCORD_CLIENT_ID` и `DISCORD_CLIENT_SECRET`.
7. **Партнёрка**: условия (500 подписчиков, 2 000 просмотров, 10%) должны совпадать в `api.mjs` и в оферте.
8. Выполнить `npm run check` и проверить вход, регистрацию с галочкой согласия и оплату на тестовом окружении.
