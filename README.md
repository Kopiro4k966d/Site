# Crysea — сайт, кабинет, оплата и партнёрская программа

Этот файл — карта проекта. Подробные инструкции по деплою и входу уже лежат рядом:
- `ИНСТРУКЦИЯ_NETLIFY.md` — как выложить сайт на Netlify;
- `ВХОД_DISCORD_GOOGLE.md` — как включить вход через Discord и Google.

## Структура

```
public/              статика сайта (открывается как есть)
  index.html         главная: hero, сравнение до/после, отзывы, тарифы, партнёрка, помощь, футер
  account.html       кабинет: обзор, пресеты, оплата, партнёрка, настройки
  admin.html         админка партнёров (нужен ADMIN_KEY)
  legal.html         оферта и политика конфиденциальности
  oauth.html, 404.html
  style.css          все стили (разделы помечены комментариями)
  script.js          переключение языка RU/EN (словарь EN), меню, основная логика главной
  account.js         кабинет: вкладки, тарифы, партнёрская панель
  auth.js            вход, регистрация, окно оплаты
  reviews.js         плавающие карточки отзывов (берутся из /api/reviews)
  admin.js           логика админки партнёров
  veil.js            фон DarkVeil (WebGL2), подключён на всех страницах
  glass.js           стеклянные поверхности (см. ниже)
  reveal.js          плавное появление блоков при прокрутке
  assets/icons/      иконки Discord и Telegram
netlify/functions/api.mjs   весь бэкенд: сессии, платежи ЮKassa, отзывы, партнёрка, админка
db/schema.sql        схема PostgreSQL
scripts/             db-init, проверка перед запуском, генерация ключей, тесты партнёрки
```

## Запуск локально

1. Скопировать `.env.example` в `.env` и заполнить переменные (см. ниже).
2. `npm install`
3. `npm run db:init` — создать таблицы в базе.
4. `npm run dev` — запуск через `netlify dev`.
5. Тесты партнёрской логики: `npm test` (работают без базы, на подменённой БД в памяти).

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `DATABASE_URL` | строка подключения к PostgreSQL |
| `SITE_URL` | адрес сайта (для ссылок оплаты и входа) |
| `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET` | боевая оплата ЮKassa |
| `LICENSE_PRIVATE_KEY` | приватный ключ лицензий (`npm run keys`) |
| `ADMIN_KEY` | ключ админки партнёров, не короче 24 символов |
| `AUTH_SECRET` | секрет сессий, не короче 32 символов |
| `DISCORD_CLIENT_ID/SECRET`, `GOOGLE_CLIENT_ID/SECRET` | вход через соцсети (можно не задавать) |
| `DEMO_PAY=1` | **только на тестовом сайте**: тариф включается без оплаты. На боевом не задавать |

Сгенерировать ключ: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`

## Партнёрская программа

- Заявка подаётся в кабинете (вкладка «Партнёрам»).
- Одобряет администратор в `/admin.html`. Активация возможна только при 500 подписчиках и 2 000 средних просмотрах (сервер проверяет).
- При одобрении создаётся личный промокод. По нему покупатель получает скидку (по умолчанию 10%, задаётся в админке).
- Партнёр получает комиссию 10% от каждой подтверждённой оплаты по своему коду. Самопокупка комиссии не даёт.
- Оплата за видео (2 видео в неделю) задаётся в админке по месяцам.
- Выплаты админ отмечает кнопкой «Отметить комиссии выплаченными».

## Визуальные модули

- **veil.js** — WebGL-фон. Нет WebGL2 — фон остаётся чёрным. Скорость и поток задаются в объекте `S`.
- **glass.js** — стекло. В Chromium крупные карточки преломляют фон (SVG-фильтр). В Safari и Firefox — размытие с подсветкой. Вложенные элементы стекла не получают (иначе появляются артефакты).
- **reveal.js** — появление блоков при прокрутке. Блоки с `data-rv` в разметке имеют приоритет.

Все анимации отключаются при `prefers-reduced-motion`.
